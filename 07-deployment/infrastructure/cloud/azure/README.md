# AZURE — optional / opcional

**English:** `plan.example.json` maps possible managed services. It creates
nothing and contains no credentials. Follow [infrastructure steps](../../README.md)
and select least-privilege identity, private storage, region and budget before
implementing adapters or deploying. Bucket/account names require provider-specific
validation; no resources or account connections have been tested.

**Español:** `plan.example.json` relaciona servicios posibles; no crea recursos
ni contiene credenciales. Seguir [los pasos de infraestructura](../../README.es.md),
elegir identidad con permisos mínimos, almacenamiento privado, región y presupuesto
antes de implementar adaptadores o desplegar. Validar nombres según el proveedor;
no se han probado recursos ni conexiones a cuentas reales.
