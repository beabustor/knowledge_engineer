# Scoped roadmap — not delivered capabilities

[Español](../es/roadmap.md)

1. Independently review/version the terminology benchmark and add genuinely held-out
   material. Keep known negation/typo errors visible; do not optimize on public tests.
2. Import an authorized edition only after its license, version and provenance are
   settled. Preserve mapping relations instead of declaring equivalence by string match.
3. Compare lexical rules with local embeddings on the same retrieval task. Adopt a
   model only when measured improvement, licensing and resource use justify it.
4. Validate Neo4j against a real server if a target role needs it; graph inspection
   and RDF are currently the demonstrated skills.
5. Deploy an authenticated proxy with shared quotas only if public usage warrants it.
   Existing `07-deployment/optional/` and `07-deployment/infrastructure/` folders are not evidence of production
   cloud experience. They remain off and have no automatic provisioning.
6. SNOMED CT and María Moliner research stays conditional on source-specific rights.
   No promise of “millions of documents”, training, complete relation extraction or
   quality gains is made. See `08-research/` for licensing and evaluation plans.
