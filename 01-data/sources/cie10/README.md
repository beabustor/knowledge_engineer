# Retired source / Fuente retirada

**English:** The third-party `cie10.xls` snapshot is no longer in the current
repository tree or browser bundle because redistribution rights were not verified.
`provenance.json` retains its source/checksum for audit; it is not permission to
redistribute. Older Git commits still contain the file. History was not rewritten.
The active demo uses project-authored text and reference IDs in `01-data/catalog.json`;
it does not claim to include a complete or officially validated ICD-10 edition.

**Español:** La copia de terceros `cie10.xls` se ha retirado de la versión actual
y de la web porque no se verificaron sus derechos de redistribución.
`provenance.json` conserva origen/checksum para auditoría, no concede permisos.
Los commits antiguos aún contienen el archivo; no se ha reescrito el historial.
La demo usa textos propios y referencias de `01-data/catalog.json`; no incluye ni
pretende ser una edición CIE-10 completa u oficialmente validada.
